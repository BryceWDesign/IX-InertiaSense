# IX-InertiaSense v0.1.0: Executed result summary

This is an executable research prototype, NOT a solution to general robotic physical adaptation. All values here are synthetic (known gravity, tared quasi-static wrench, generated link characteristics).

## Static payload identification, 240 independent simulated episodes

| Arm morphology | Condition | Robust median 3D CoM error (mm) | OLS median CoM error (mm) | Robust median mass error (g) | OLS median mass error (g) |
|---|---|---:|---:|---:|---:|
| compact_arm | clean | 0.203 | 0.203 | 0.70 | 0.70 |
| compact_arm | sensor_noise | 0.459 | 0.459 | 1.85 | 1.85 |
| compact_arm | impulsive_outliers | 0.764 | 7.666 | 2.37 | 20.15 |
| extended_arm | clean | 0.226 | 0.226 | 0.96 | 0.96 |
| extended_arm | sensor_noise | 0.357 | 0.357 | 1.22 | 1.22 |
| extended_arm | impulsive_outliers | 0.721 | 6.310 | 2.90 | 17.19 |

No evidence of an accuracy improvement was observed in ordinary clean data. Robust reweighting gave greater resistance to artificially injected extreme wrenches, as expected from established Huber estimation. Data are generated by the same quasi-static equations used by both estimators; this is an *inverse crime* for external validity.

## Payload replacement benchmark, 40 additional synthetic episodes

| Morphology | Trials | Missed / premature detections | Median additional samples after first changed sample | Final mass MAE median (g) | Final CoM error median (mm) |
|---|---:|---:|---:|---:|---:|
| compact_arm | 20 | 0 | 4 | 1.21 | 0.129 |
| extended_arm | 20 | 0 | 4 | 1.07 | 0.141 |

The change-event counter uses five consecutive anomalous observations; the table reports **zero-based additional samples after the first changed sample**, not a physical response-time measurement. The tracking model assumes known stationary conditions and cannot infer actual unobserved robot physics.

## Reproduction commands

`cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build && ctest --test-dir build --output-on-failure`

`python benchmarks/benchmark.py --binary build/inertiasense --repeats 40 --output results/new_static.json`

`python benchmarks/change_benchmark.py --binary build/inertiasense --repeats 20 --output results/new_change.json`

Windows command differences in README. No ROS 2 runtime or real robot was tested. GitHub CI outcome can only be established after actual push.
